# Unihelper

Персональный консультант по поступлению за рубеж на грант для школьников и студентов 1–2 курса из Узбекистана.
Основа — экспертная система (правила и веса по каждой программе), ИИ только объясняет и советует.
Планы: «Unihelper — план продукта и вайбкодинга» и «Unihelper — обновления v1.1 и v1.2».

## Стек
Next.js 15 App Router, TypeScript strict, Tailwind v4 (токены дизайна в `app/globals.css`), Supabase (Postgres + RLS),
ИИ через `lib/server/llm.ts` (по умолчанию бесплатный Gemini через OpenAI-совместимый API; Claude и любой OpenAI-совместимый провайдер — переменной `AI_PROVIDER`), Vitest.

## Структура
- `components/auth/AuthGate.tsx` — вход обязателен: кабинет `app/(app)` (кроме `/pricing`) и мок `/mocks/run` только для вошедших с анкетой; не вошёл → экран входа (виден и в HTML с сервера; у вошедших до проверки сессии прячется CSS по флагам `data-auth`/`data-demo` из скрипта в `<head>`), вошёл без анкеты → `/quiz?next=…`. Анкета — первый шаг регистрации: после неё `LoginCard mode="register"`, данные браузера переносятся в аккаунт (`mergeStates`). Перенаправлять на анкету только после `stateReady` (данные аккаунта подтянуты). Вход (`components/auth/LoginCard.tsx`) рассчитан на телефон: Telegram — виджет с `data-auth-url` → `/auth/telegram` (без всплывающего окна; понимает и `#tgAuthResult`); письмо — неявный поток (`supabaseEmailLink()`), ссылка срабатывает в любом браузере, токены разбирает `/auth/callback`; ввод кода из письма — только при `NEXT_PUBLIC_EMAIL_OTP=1` (нужен свой SMTP в Supabase, чтобы добавить `{{ .Token }}` в шаблон); во встроенных браузерах соцсетей — подсказка вместо Google
- `app/(site)` — лендинг и анкета; `app/(app)` — кабинет с боковым меню (главная, программы, карта, моки, ивенты, уроки, AI Advisor, эссе, портфолио, профиль); `app/(exam)/mocks/run` — прохождение мока без меню
- `app/api/` — `profile`, `advice`, `chat`, `leads`, `mocks/*` (start, submit, check, event, review, writing), `lessons`, `ai/essay`, `ai/portfolio`
- `lib/scoring/` — Profile Strength, Admission Fit, Funding Fit, подбор. Пороги — в `config.ts`
- `lib/mocks/` — банки вопросов (`bank/`), движок (`engine.ts`), подписанный токен попытки (`token.ts`), учёт прерываний (`attemptStore.ts`). Генерация: ID варианта `<база>~<сид base36>` — `getQuestion` восстанавливает вопрос на сервере (Math — шаблон с сидом, RW — `bank/rwGen.ts` или перемешанные варианты). IELTS Reading из пула ИИ — `lib/server/readingPool.ts` (текст → вопросы → независимое решение; сохраняются только совпавшие), перед проверкой — `ensurePoolQuestions`. Калькулятор уровня Desmos — `lib/calc/` (разбор в дерево без eval → замыкания, модель строк, особые точки и регрессия, отрисовка на canvas) + `components/calc/` (панель в моке, страница `/mocks/calculator`; официальный Desmos — только при `NEXT_PUBLIC_DESMOS_API_KEY`)
- `app/(app)/mocks/report` + `app/api/scores/analyze` + `lib/scores.ts` (Overall, разбор текста и даты, разбор по правилам) + `lib/server/scoreReport.ts` (PDF через `unpdf`, картинки — в `llm()` как `images`) — разбор своего результата IELTS/SAT; результаты — `store.scores`, график — `components/IeltsTrend.tsx`
- `config/` — структура моков, таблицы пересчёта SAT и IELTS (калибровать вручную)
- `lib/roadmap.ts` — дорожная карта по шаблонам; `lib/content/` — уроки и ивенты
- `data/programs.ts` — программы и гранты (источник для `supabase/seed.sql`)
- Вузы из справочника 10 000+: `lib/uniProfile.ts` (тип, перевод профиля в программу) + `lib/uniProfileSchema.ts` (схема ответа ИИ, только сервер) + `lib/server/uniProfile.ts` (общий кеш `uni_profiles`, ИИ собирает один раз на вуз и язык) + `app/api/universities/profile` + `components/programs/UniDetails.tsx` (полная карточка, «О вузе» в подробностях программы). Ученик ничего не заполняет: «Добавить и оценить» в один клик; ручная форма — только если данных нет. Данные помечены «собрано ИИ, не проверено экспертом»
- `components/` — оболочка, карточки, компоненты мока, тур демо
- `app/(admin)/admin` + `app/api/admin/*` + `components/admin/*` — админка; контент = код + правки (`lib/server/contentStore.ts`), сайт читает итог через `/api/content` и `useContent()`
- Перевод сайта на uz/en: `lib/i18n/dict/{uz,en}.json` (ключ — русский текст с нормализованными пробелами, числа → «#»), `lib/i18n/translate.ts` (поиск, составные строки по частям), `lib/i18n/dom.ts` (перевод отрисованной страницы: текст и placeholder/title/aria-label/alt, наблюдатель за изменениями), `lib/i18n/lang.ts` (язык в `uh-lang`, общий с лендингом), `components/I18n.tsx` (словарь грузится чанком только для uz/en; до применения страница скрыта, не дольше 3 с), `components/LangSwitch.tsx`. Пополнение: `npm run i18n:translate` (строки из кода + `scripts/i18n-extra.json` → ИИ; даты — через Intl, `scripts/i18n-dates.mjs`), `node scripts/i18n-crawl.mjs <url>` — собрать строки с живых страниц. Язык ответов ИИ — заголовок `x-uh-lang` (ставит `apiFetch`) → `langOf(req)` + `LANG_RULE` в `lib/server/replyLang.ts`
- `components/landing/LandingV4.tsx` + `lib/i18n/landing.ts` — лендинг на 3 языках (свои словари); тема — `data-theme` на <html>, токены v4 в `app/globals.css`
- `lib/telegram/bot.ts` (логика, тесты) + `lib/server/tgBot.ts` (вызовы API) + `app/api/telegram/{webhook,link,cron}` + `app/(site)/tg` + `components/TelegramBridge.tsx` — бот и мини-приложение. Вебхук проверяет секрет, обработка — через `after()`. Мини-апп помечает вкладку `sessionStorage uh-tg`; хард-режим моков в Telegram запрещён (`inTelegram()`)
- `app/(site)/blog`, `app/(site)/courses` + `lib/content/posts.ts` + `components/site/*` — публичный блог (контент-тип `posts`, правится в `/admin/blog`) и бесплатные уроки без регистрации; текст статей — простой формат без HTML (`components/site/Prose.tsx`)
- `app/(app)/community` + `app/api/community/*` + `lib/community.ts` + `lib/server/community.ts` — комьюнити: карточки участников, проекты «ищу команду», организации с общим чатом, личные чаты (опрос раз в 4 с), жалобы → `/admin/community`, блокировки. Только для вошедших; таблицы `community_*` закрыты RLS, доступ через service role
- UniCoins: `lib/coins.ts` (задания, награды, магазин) + `lib/server/coins.ts` + `app/api/coins/*` + `app/r/[code]` + `components/coins/*`, `components/ProLock.tsx` (`ProGate`, `CoinUnlockButton`). Баланс = сумма `coin_ledger`; начисления — `coin_award` (один раз на reason+ref), списания — `coin_spend` с блокировкой; разовые открытия — `coin_unlocks`, тратятся в закрытых API через `consumeUnlock`. Игра: уровни по опыту (все заработанные монеты), достижения, ежедневные задания, монеты за прогресс (новый максимум силы профиля, личный рекорд мока, шаги дорожной карты) — чистый расчёт `lib/coinProgress.ts` (с тестами), сервер исполняет при `GET /api/coins`; точки отсчёта — `user_state.coin_progress` (пишет только сервер)
- `app/p/[slug]` + `app/api/portfolio` + `lib/portfolio.ts` + `components/portfolio/` — публикация сайта-портфолио: в базу уходит только публичный снимок, «по ссылке» = noindex + ключ `k`, до 18 лет — согласие родителя
- Родители: `app/(app)/parent` (кабинет родителя, без анкеты: роль `store.role = "parent"`) + `app/(site)/join/[code]` (приглашение для ребёнка) + `app/api/family/*` + `lib/family.ts` (сводка прогресса, чистая, с тестами) + `lib/server/family.ts` + `components/family/*` (форма ребёнка, блок «Родители» в профиле). Таблица `parent_links`, код ребёнка — `user_state.parent_code`
- `app/(site)/demo` + `lib/demo.ts` + `lib/demoData.ts` + `app/api/demo` — демо для инвесторов (вымышленный ученик, история моков считается настоящим движком)
- Оценки по предметам: `lib/grades.ts` (распознавание предметов ru/uz/en — шаблоны в `lib/gradeAliases.ts`, средний без физкультуры/музыки, профильные предметы по направлениям `MAJOR_SUBJECTS`, разбор вставленной таблицы, класс из группы) + `profile.grades` → GPA по оценкам (`profileGpa100`), ось «Учёба» (профильные ±8, спецпредметы до +4, `SUBJECT_RULES`), слабый профильный предмет — не выше «Реалистично». Импорт: `components/grades/*` (профиль) + `app/api/grades/import` → `lib/server/emaktab.ts` (вход в eMaktab как браузер: форма login.emaktab.uz, капча — ученику, состояние шифруется на 10 мин; отметки за учебный год из `/api/v2/marks/diary`; пароль не хранится и не логируется) или `lib/server/gradesPhoto.ts` (фото/PDF табеля, EMIS — скриншот). Прямого входа в EMIS нет; диагностика связи — `/admin/integrations`
- Страны: любая страна мира (`ALL_COUNTRIES`, `POPULAR_COUNTRIES` в `lib/countries.ts`, `components/CountryPicker.tsx`); без шаблона сроков дорожная карта ставит «уточни сроки на сайтах вузов»
- Подбор из общей базы: `lib/server/uniPool.ts` + `app/api/universities/pool` (карточки `uni_profiles` по странам ученика; если мало — в фоне `after()` дособирает по `data/uniSeeds.ts` или списку страны от ИИ, таблица `uni_country_tops`) + `lib/useUniPool.ts` (`poolProgram`, id `pool-…`). Добавленный в «Мой список» вуз из базы хранится копией в `customUnis` с `pooled: true` (в лимит своих вузов не входит). «Подбор обновился» — `lib/matchDiff.ts` + `store.matchSnap`
- Онлайн-ивенты: `lib/onlineEvents.ts` (разбор Devpost/Codeforces/CodeChef и подбор под профиль — чистые функции с тестами) + `lib/server/onlineEvents.ts` + `app/api/events/online` + `components/events/OnlineForYou.tsx` («В мой план» → `customSteps`)
- AI Advisor: `app/(app)/assistant` + `components/advisor/CatMascot.tsx` (Юни, анимации — CSS `.cat-*` и токены `--cat-*` в `globals.css`) + `components/advisor/RichText.tsx` (оформление ответа без HTML). ИИ — цепочка провайдеров в `lib/server/llm.ts` (`chain`): основной + запасные с ключами (`GROQ_API_KEY`, `MISTRAL_API_KEY`, `CEREBRAS_API_KEY`, `OPENROUTER_API_KEY`, порядок `AI_FALLBACKS`); стрим переключается, только пока ничего не отдал
- Синхронизация: неотправленные изменения помечены (`unihelper:pending`, `pendingSince`/`markSynced`) — при загрузке они важнее данных аккаунта; при уходе со страницы изменения уходят сразу (`keepalive`)

## Правила
- Никаких процентов «шансов». Сила профиля — шкала 1–100 (`STRENGTH_POINTS` в `lib/scoring/config.ts`), подписывается «из 100» и «не шанс поступления», без знака %. Admission Fit и Funding Fit никогда не смешиваются в одно число.
- Жёсткие правила: полный грант — максимум «Реалистично»; «Высокое соответствие» невозможно без оценённых эссе/рекомендаций и при acceptance rate < 20%.
- Метку ставит код в `lib/scoring`, ИИ только объясняет. Изменение правил — с тестом.
- Моки: правильные ответы никогда не уходят на клиент до завершения модуля (`toPublic`). Балл — диапазоном с подписью «примерная оценка». Мок-балл идёт в Profile Strength «по моку» и не используется для требований вузов.
- Хард-режим: только десктоп вне Telegram, полный экран; выход/смена вкладки/blur/закрытие → попытка прервана.
- Файл с результатом экзамена не сохраняется нигде; ИИ берёт только баллы и дату, без имени, номера кандидата и даты рождения.
- Импорт оценок: пароль eMaktab используется один раз для входа и нигде не сохраняется и не пишется в логи; файлы табеля не сохраняются; берём только предметы и оценки (и класс), без имени ученика.
- Онлайн-ивенты — только из источников с датами от организаторов (Devpost, Codeforces, CodeChef, лента); ИИ ивенты и даты не придумывает.
- Вопросы — только свои (код/человек/ИИ + проверка). Не копировать College Board, Cambridge, Engnovate.
- Партнёрство вуза не влияет на метки и порядок; контакт уходит вузу только по кнопке и с согласием.
- ИИ не пишет эссе за ученика и не выдумывает дедлайны и суммы. Все вызовы ИИ — только через `llm()`; у каждой ИИ-функции есть запасной вариант без ИИ.
- Без входа доступны только лендинг, анкета (начало регистрации), демо, блог, курсы, тарифы и опубликованные портфолио. Весь функционал — после регистрации через Telegram, Google или почту, и только с заполненной анкетой.
- Демо: данные явно помечены как вымышленные; в демо лиды и профиль никуда не отправляются, комьюнити и публикация портфолио недоступны.
- Родители видят прогресс ребёнка только с его согласия: ребёнок сам даёт код или принимает приглашение и может отключить родителя в профиле. Родителю — только итоги (сила профиля, моки, план, уроки, вузы, монеты), без переписки, эссе и контактов.
- Комьюнити: участники — несовершеннолетние. Контакты не показываются, общение внутри сайта, перед отправкой телефона/адреса — предупреждение, у каждого сообщения/карточки/проекта — «Пожаловаться», блокировка скрывает людей друг от друга.
- Данные с `verifiedAt = null` и ивенты-примеры явно помечены.
- Pro-функции закрываются заметно: `ProGate` (размытый пример, не настоящие данные) или `ProLock` с замком; где есть товар в магазине — кнопка «за UniCoins». Начислять и списывать монеты — только на сервере.
- Аналитика: только через `track()` из `lib/analytics.ts` (уходит лишь с согласия), без имён, контактов, текстов и ID людей в параметрах; адреса чистит `sanitizePath`.
- Ключи только в `.env.local` и настройках Vercel. Service role — только в `lib/server`.
- Новые страницы берут программы/ивенты/уроки только через `useContent()` (клиент) или `getContent()` (сервер), не из констант напрямую.
- Цвета — только токены из `globals.css` (работают в обеих темах); тёмные карточки — `bg-inv`/`inv-card`, не `bg-ink`.
- Мобайл-first (375px): в кабинете нижняя панель `TabBar` (AppShell) и шапка в одну строку, ряды вкладок — утилита `tabs-row`, кнопки не меньше ~36px. Без эмодзи в интерфейсе, иконки — штриховые SVG из `components/icons.tsx`.
- Новый русский текст в интерфейсе — перед коммитом `npm run i18n:translate`. Пользовательский текст (имена, сообщения, посты, ответы ИИ) — с `translate="no"`, чтобы словарь его не трогал.
- Скорость: никаких `backdrop-filter` у карточек и движущихся элементов (только редкие панели `glass`), фон — статичные градиенты; тяжёлые библиотеки — динамическим `import()` (`supabase-js` грузится после отрисовки, сессия сначала берётся из localStorage); `useStore()` — общий снимок через `useSyncExternalStore`.
