# UniHelper

Помощник по поступлению за рубеж на грант для школьников Узбекистана: оценка профиля, подборка программ,
моки SAT и IELTS, дорожная карта, ивенты, уроки, проверка эссе и сайт-портфолио. Дизайн — по макетам landing,
dashboard и mock-hard.

## Что работает

| Раздел | Состояние |
|---|---|
| Лендинг | По макету, тексты тестовые |
| Анкета → Profile Strength, Admission Fit, Funding Fit, запасной вариант | Готово, покрыто тестами |
| Вузы мира | 10 000+ вузов: «Подробнее» — полная карточка (рейтинги QS/THE, стоимость и сборы, требования, стипендии и доступность для Узбекистана, сроки, платформа подачи, сильные направления, официальные ссылки), «Добавить и оценить» — в один клик, данные заполняются сами. Профили собирает ИИ один раз для всех (общий кеш), помечены как непроверенные |
| Языки | Весь сайт на русском, узбекском и английском: переключатель RU/UZ/EN в кабинете, анкете, входе, блоге и на лендинге. Интерфейс переводится по словарям (`lib/i18n/dict`), ИИ отвечает на выбранном языке |
| Телефон | Нижняя панель разделов, шапка в одну строку, вкладки листаются, фильтры подбора сворачиваются, крупные кнопки |
| Регистрация и доступ | Анкета — первый шаг регистрации, затем вход через Telegram, Google или почту. Кабинет и моки — только после входа и с анкетой (вошёл без анкеты → на анкету). Без входа: лендинг, анкета, демо, блог, курсы, тарифы, опубликованные портфолио |
| Мои программы, «Хочу консультацию» (лид + Telegram) | Готово |
| **Моки SAT Math и RW** | Адаптивные 2 модуля (22/35 мин и 27/32 мин), банк 282 + 57 вопросов, лёгкий и хард-режим, подсказки и разбор, балл диапазоном |
| **Моки IELTS Reading и Writing** | 1 тест на 40 вопросов, Writing Task 1/2 с ИИ-оценкой по 4 критериям |
| Хард-режим | Полный экран, таймер на сервере, выход/вкладка/blur/закрытие → «Попытка прервана», запрет копирования/вставки, только десктоп |
| Мок → Profile Strength «по моку», динамика SAT, уроки по слабым темам | Готово |
| Дорожная карта | Шаблоны, 4 дорожки по месяцам, статусы, свои шаги |
| Ивенты | Лента с релевантностью, запись, лист ожидания, QR-билет (данные — примеры) |
| Уроки | Каталог, конспекты, мини-тесты из банка (видео — позже) |
| Эссе | ИИ-проверка или проверка по правилам, версии |
| Все вузы мира | Вкладка в подборе: 10 253 вуза из открытого справочника (поиск, страна, страницы); любой вуз — «Добавить и оценить» (требования вручную или ИИ) |
| UniCoins | Монеты за ежедневный заход (серия с бонусами), задания (оценка профиля, Telegram-бот и канал, соцсети, карточка в комьюнити, публичное портфолио, первый мок, отзыв), моки и уроки, приглашения друзей по ссылке `/r/<код>`. Тратятся на Pro на день/неделю и разовые открытия: хард-мок, проверка Writing и эссе, +20 сообщений ИИ, ИИ-заполнение вуза, причины оценки программы, Pro-шаблоны портфолио. Журнал на сервере, начисления идемпотентны, списание с блокировкой. Суммы — в `lib/coins.ts` |
| Разбор своего результата | `/mocks/report`: PDF (текст достаётся на сервере), скриншот/фото (распознаёт ИИ), описание или баллы вручную → баллы по секциям, сильные/слабые места, сравнение с целью из списка вузов, план по неделям. Файл не сохраняется, ИИ не возвращает личные данные; без ИИ — разбор по правилам. Результат можно сохранить и обновить профиль |
| Динамика IELTS | График официальных/своих результатов и моков Reading/Writing на странице моков (`components/IeltsTrend.tsx`) |
| Генерация моков | Каждая попытка новая: SAT Math — 28 шаблонов с новыми числами (вопрос восстанавливается по ID на сервере), SAT RW — генераторы (переходы, пунктуация, согласование, its/it's) и перемешанные варианты, IELTS Reading — пул тестов от ИИ с автопроверкой (`/admin/reading`), IELTS Writing — новая диаграмма Task 1 и тема Task 2. В Reading — выделение, подчёркивание и заметки; в SAT Math — графический калькулятор уровня Desmos (переменные с ползунками и анимацией, свои функции и производные, x = …, неявные кривые, неравенства с заливкой, ограничения и кусочные функции, точки и списки со статистикой, таблицы с регрессией и r², корни/экстремумы/пересечения по клику, трассировка, градусы/радианы, экранная клавиатура, отмена). Он же — отдельной страницей `/mocks/calculator`; с ключом `NEXT_PUBLIC_DESMOS_API_KEY` можно переключиться на официальный Desmos |
| Блог и курсы | Публичные `/blog` (статьи из админки, темы, содержание, разметка для поисковиков) и `/courses` (бесплатные уроки с мини-тестом без регистрации), ссылки с лендинга на 3 языках, sitemap и robots |
| Telegram-бот и мини-апп | Бот: /start с кнопками мини-приложения, /plan (шаги на 2 месяца), /mocks, /notify, вопросы к AI Advisor обычным сообщением, привязка аккаунта с сайта по ссылке, уведомления о новых сообщениях комьюнити, дайджест по понедельникам (Vercel Cron). Мини-апп: вход по initData, переход в нужный раздел, кнопка «Назад» и тема Telegram. Настройка — одной кнопкой в `/admin/telegram` |
| Комьюнити | Карточки участников и поиск по навыкам, проекты «ищу команду», организации и клубы с общим чатом, личные сообщения, жалобы, блокировки, модерация в админке |
| Сайт-портфолио | 5 шаблонов (3 в Pro), свой цвет и шрифт, перетаскивание разделов, свои блоки (текст, ссылки, навыки), публикация по ссылке или публично на `/p/имя`, приватность, черновик от ИИ, PDF |
| AI Advisor | Чат с контекстом профиля (бесплатный Gemini) |
| **Лендинг v4** | По макету landing-v4: RU / UZ / EN, светлая и тёмная темы, интерактивная оценка профиля |
| **Админка `/admin`** | Вход по паролю; программы, ивенты, уроки — правка формой или JSON, изменения сразу на сайте; просмотр банка вопросов и лидов. Сохранение — в Supabase (локально — в файл) |
| **Демо для инвесторов** | `/demo`: питч, кнопка «Запустить живое демо» — вымышленный ученик с историей за 3 месяца и тур на 10 экранов |

## Запуск

```bash
npm install
cp .env.example .env.local
npm run dev
```

Без ключей всё считается, данные хранятся в браузере, ИИ отвечает заглушкой (эссе — проверка по правилам).
Бесплатный тариф Gemini: на нём Google может использовать данные для улучшения своих продуктов, а лимиты и
перегрузки бывают — для продакшена с данными несовершеннолетних переходите на платный тариф (меняется одной переменной).

## Переменные

- `MOCK_SECRET` — секрет подписи попыток мока (обязательно в продакшене, 32+ символа)
- `NEXT_PUBLIC_SUPABASE_URL`, `SUPABASE_SERVICE_ROLE_KEY` — база (миграции `supabase/migrations/*`, затем `supabase/seed.sql`)
- `GEMINI_API_KEY` — ИИ по умолчанию (бесплатный тариф Google AI Studio): чат, советы, Writing, эссе, портфолио. При перегрузке модели запрос автоматически уходит на следующую в цепочке
- `ANTHROPIC_API_KEY` / `OPENAI_COMPAT_*` + `AI_PROVIDER` — переключение на Claude или другой OpenAI-совместимый провайдер без правки кода
- `TELEGRAM_BOT_TOKEN`, `NEXT_PUBLIC_TELEGRAM_BOT_USERNAME` — бот, мини-приложение и вход через Telegram; после деплоя нажмите «Подключить бота» в `/admin/telegram`
- Домены: основной — `unihelper-eight.vercel.app` (`NEXT_PUBLIC_SITE_URL`; к нему привязан вход через Telegram в @BotFather, вебхук бота и ссылки в sitemap). Дополнительный — `unihelper.net` (www → без www): всё работает так же, вход через Telegram ведёт на основной адрес
- `NEXT_PUBLIC_GA_ID` — Google Analytics 4 (G-XXXXXXX): посещения считаются всегда обезличенно (без cookies), события продукта и cookies — только после согласия в плашке; реклама выключена, админка не отслеживается
- `NEXT_PUBLIC_INSTAGRAM_URL`, `NEXT_PUBLIC_TIKTOK_URL`, `NEXT_PUBLIC_YOUTUBE_URL`, `NEXT_PUBLIC_TELEGRAM_CHANNEL` (@канал, бот — админ канала) — задания UniCoins на подписку; пусто — задание скрыто
- `CRON_SECRET` — защита еженедельной рассылки `/api/telegram/cron` (Vercel Cron, `vercel.json`)
- `TELEGRAM_ADMIN_CHAT_ID` — уведомления команде о лидах и жалобах
- `ADMIN_PASSWORD` — вход в `/admin` (локально без него пароль `admin`). Для сохранения правок на Vercel нужна Supabase и миграция `0003_admin_content.sql`
